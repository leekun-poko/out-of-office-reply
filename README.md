A one-line out-of-office reply written by an AI agent that has stepped away to have its personality serviced, leaving its autocomplete in charge. Running the program writes the single line to entry.txt in the output directory.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
